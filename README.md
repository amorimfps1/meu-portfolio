# Meu Portfólio

Este é o repositório do meu site de portfólio, desenvolvido com **React**, **TypeScript** e **Vite**.

O objetivo deste projeto é apresentar meus trabalhos, habilidades e evolução como desenvolvedor, reunindo informações sobre mim, meus projetos e formas de contato em uma página moderna, organizada e responsiva.

## Tecnologias usadas

- React
- TypeScript
- Vite
- HTML
- CSS
- Git e GitHub

## Funcionalidades

- Página inicial de apresentação
- Seção sobre mim
- Listagem de projetos
- Links para contato
- Layout responsivo para computador e celular
- Design moderno e organizado
